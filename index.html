From intent to continuous action

RoBIOS turns human instructions into physical execution. The kernel and plugins manage action state, feedback, and embodied capabilities.

1. Why RoBIOS?

In the “digital agent + physical tools” model, a Robot-Use Agent plans and sends tasks while the tools execute passively. Physical feedback is delayed and actions are irreversible, exposing two gaps in this design.

Design dimensionRobot-Use AgentRoBIOS
01Safety fallbackThe digital agent is removed from the physical scene. If an instruction is unsafe or the scene changes, the passive tool has no local authority to intervene.The physical kernel checks admission, monitors execution, and handles exceptions on site.
02Real-time feedbackStreaming every high-frequency state change to a large model raises inference cost and latency, limiting real-time response.The kernel closes the fast loop locally and sends summarized state to the digital agent when higher-level replanning is needed.

RoBIOS’s key distinction: The physical kernel governs execution; the digital agent handles planning.

Design principles

Control granularity follows the budget
Balance execution quality, feedback frequency, and inference cost within the available budget.
Capabilities grow through plugins
Compose and reuse capabilities around a stable kernel.

2. Framework

The planning layer proposes tasks, and the physical kernel manages execution. Plugins provide action capabilities, human–robot interaction, memory, and adapters for robots and simulation environments.

3. Physical kernel

Execution decisions
Decide whether to allow, block, or stop an action based on admission results, resource usage, and safety state.
State management
Maintain task progress, execution records, observation evidence, and acceptance results in a unified state.
Closed-loop scheduling
Coordinate the stages, using feedback to advance the task or request replanning.
Exception handling
Manage timeouts, failures, pauses, recovery, and cancellation; track stop confirmation and task finalization.
